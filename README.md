При составление технического задания часто используются повторяющиеся требования, модели, сценарии. В рамках проекта будет выполняться разработка рекомендательной системы для поиска и составления рекомендаций на базе существующих проектов

Problem Statement: при составление списка требований, аналитики тратят большое количество времени, расписывая требования под каждую систему вручную, иногда допуская логические неточности. Такая рутинная работа может занимать дни и даже недели, тем самым замедляя процесс разработки конечного продукта, заставляя бизнес терять деньги из-за простоя

Goal: рекомендательная система для поиска и составлений рекомендаций на базе существующих проектов обеспечит аналитикам возможность сократить рутинную работу, освобождая время под детальное изучения тонкостей каждой системы, для детальной проработки требований. Аналитик получает больше времени для проработки нефункциональных требований(следования требованию всех необходимых Гостов, законов и других правовых формальностей), что напрямую влияет на возможность использования системы заказчиком
